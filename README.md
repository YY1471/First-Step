# Plant Well 植物井

仿照《动物井》(Animal Well) 风格的 2D 平台跳跃游戏原型。目前包含一个房间场景、一个角色，支持左右移动与跳跃。

## 运行方式

用 **Godot 4.4 或更高版本**打开本项目（`project.godot`），按 `F5` 运行。

## 操作

| 按键 | 动作 |
| --- | --- |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` / `W` / `↑` | 跳跃 |

跳跃支持可变高度（上升中松开按键跳得更低）、土狼时间与跳跃缓冲，手感接近《动物井》。

## 项目结构

```
├── project.godot          # 项目配置（输入映射、窗口、渲染）
├── icon.svg               # 项目图标
├── scenes/
│   ├── main.tscn          # 主场景（背景 + 萤火虫 + 平台 + 玩家）
│   └── player.tscn        # 玩家场景（角色体 + 碰撞 + 视觉 + 相机）
└── scripts/
    ├── player.gd          # 移动与跳跃物理
    ├── player_visual.gd   # 角色外观（种子团子，纯代码绘制）
    ├── glow.gd            # 角色光晕
    ├── platforms.gd       # 平台布局与外观（改 PLATFORMS 数组即可改关卡）
    ├── fireflies.gd       # 漂浮的萤火虫
    └── background.gd      # 背景渐变与植物剪影
```

所有画面均为代码绘制，无需任何图片素材。
