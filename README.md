# Plant Well 植物井

像素风格的 2D 平台跳跃游戏原型。包含主菜单、存档系统与一个可探索的林地房间。

## 运行方式

用 **Godot 4.4 或更高版本**打开本项目（`project.godot`），按 `F5` 运行。

## 操作

| 按键 | 动作 |
| --- | --- |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` / `W` / `↑` | 跳跃 |
| `S` / `↓` | 下穿悬浮平台 |
| `ESC`（游戏中） | 打开/关闭暂停菜单 |

暂停菜单：**继续游戏**（回到游戏）、**选项**（全屏与音量）、**返回主菜单**（自动保存后退出到主菜单）。

## 菜单操作

| 输入 | 动作 |
| --- | --- |
| `W`/`A`/`S`/`D` 或方向键 | 移动焦点 |
| `回车` / `空格` | 确认（激活按钮） |
| `Home` / `End` | 跳到首个 / 末尾控件 |
| `PgUp` / `PgDn` | 聚焦滑条时 ±10% 调值，否则跳首/尾 |
| 鼠标 | 悬停高亮、点击按钮、滚轮调滑条 |

跳跃支持可变高度（上升中松开按键跳得更矮）、土狼时间与跳跃缓冲，手感紧凑。

## 主菜单

- **开始游戏**：从存档槽 1 开始新游戏（会覆盖该槽，有存档时弹确认框）
- **继续游戏**：加载最近保存的存档（无存档时置灰）
- **加载游戏**：从 3 个存档槽中选择加载，显示保存时间
- **选项**：全屏开关、主音量/音乐/音效调节（自动保存到 `user://options.cfg`）
- **退出**：退出游戏

## 存档

- 存档文件位于 `user://saves/slot_N.json`，记录玩家位置
- 游戏内触碰右上角高台的**发光花**即可保存；按 ESC 返回主菜单时也会自动保存

## 项目结构

```
├── project.godot            # 项目配置（输入映射、窗口、渲染、自动加载、音频总线）
├── default_bus_layout.tres  # 音频总线：Master / Music / SFX
├── icon.svg                 # 项目图标
├── assets/
│   └── music.wav            # 背景音乐（代码合成的环境音乐，19.2s 无缝循环）
├── scenes/
│   ├── menu.tscn            # 主菜单场景（默认启动场景）
│   ├── pause_menu.tscn      # 暂停菜单场景（继续游戏 / 选项 / 返回主菜单）
│   ├── options_panel.tscn   # 选项面板（主菜单与暂停菜单共用）
│   ├── main.tscn            # 主场景（背景 + 萤火虫 + 平台 + 玩家 + 存档花 + HUD + 暂停菜单）
│   └── player.tscn          # 玩家场景（角色体 + 碰撞 + 视觉 + 相机）
└── scripts/
	├── save_manager.gd      # 存档与选项管理（自动加载单例）
	├── music.gd             # 背景音乐播放器（自动加载单例）
	├── menu.gd              # 主菜单界面（纯代码构建）
	├── pause_menu.gd        # 暂停菜单（打开时冻结游戏世界）
	├── options_panel.gd     # 共用选项面板（全屏 + 音量）
	├── ui_theme.gd          # 共用 UI 配色与控件工厂
	├── ui_nav.gd            # 菜单键盘/鼠标导航（WASD、Home/End、PgUp/PgDn、滚轮）
	├── main.gd              # 主场景逻辑（ESC 打开暂停菜单）
	├── player.gd            # 移动与跳跃物理
	├── player_visual.gd     # 角色外观（种子团子，纯代码绘制）
	├── glow.gd              # 角色光晕
	├── platforms.gd         # 平台布局与外观（改 PLATFORMS / SLOPES 数组即可改关卡）
	├── save_flower.gd       # 存档点（发光花）
	├── hud.gd               # 游戏内提示
	├── fireflies.gd         # 漂浮的萤火虫
	└── background.gd        # 背景渐变与植物剪影
```

画面与音乐均为代码生成，无需任何外部素材。
